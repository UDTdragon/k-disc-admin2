# k-DISC 조직관리 메인 화면

Figma의 `메인` 프레임을 GitHub Pages에서 확인할 수 있도록 HTML, CSS, JavaScript로 구현한 정적 사이트입니다.

## 로컬에서 확인

`index.html`을 브라우저로 열거나 간단한 정적 서버를 실행하세요.

```bash
python -m http.server 8000
```

이후 `http://localhost:8000`에서 확인할 수 있습니다.

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소에 푸시합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택합니다.
4. 배포 브랜치와 `/ (root)`를 선택한 후 저장합니다.

별도의 빌드 과정은 필요하지 않습니다.
